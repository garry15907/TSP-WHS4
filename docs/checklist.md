## 보안 체크

- [x] 모든 상태 변경 요청에 CSRF 토큰이 포함되었습니다.
결과: `csrf-sync`를 적용했습니다.
- [x] 인증 요청에 rate limit가 적용되었습니다.
결과: `express-rate-limit`를 적용했습니다.
- [x] 비밀번호가 평문으로 저장되지 않았습니다.
결과: `bcryptjs` 해시 저장을 적용했습니다.
- [x] SQL 쿼리에 prepared statement가 사용되었습니다.
결과: `node:sqlite` prepared statement를 사용했습니다.
- [x] 입력 길이와 형식 검증이 서버에서 수행되었습니다.
결과: `zod` 기반 서버측 검증을 적용했습니다.
- [x] 자기 자신에게 송금/신고가 차단되었습니다.
결과: 서버 로직 구현을 완료했습니다.
- [x] 중복 신고가 차단되었습니다.
결과: DB UNIQUE 제약과 예외 처리를 적용했습니다.
- [x] 이미지 입력은 URL만 허용했습니다.
결과: 업로드 취약점 회피를 위해 URL 기반으로 제한했습니다.
